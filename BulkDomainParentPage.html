(OneTrust Cookie Consent)  ·  Bulk Domain Management

Many domains. One CMP script.

Bring websites with similar tracking technology configurations into a domain group. Deploy the parent domain's script across the group and simplify ongoing script management, while keeping consent separate on each domain.

Create the domain group with the Create Domain Group API. Add hostnames without the protocol, then publish the parent's production script so the group can take effect.

Tip: If the domain list returns a blob error, the parent's production script may not be published yet.

When adding new domains to an existing group, set removeExisting to false to keep the current domains and add the new ones.

let body = JSON.stringify({
  "removeExisting": false,
  "urls": ["test1.com", "test2.com", "test3.com"]
});
Watch out: setting it to true, or leaving it out, can replace the existing domain list.

Check whether a URL belongs to the group, then view the full domain list in a browser.

# Check a URL (headers: location, domainId, url)
GET https://cookies-data.onetrust.io/bannersdk/v1/domaingroupcheck
# Response → { "isValid": true }

# List every domain in the group
https://cdn.cookielaw.org/consent/{domainId}/domain-list.json
Tip: check the Network tab to confirm which domain's script loads on each site.

To move away from Bulk Domain Management, each domain needs a standard setup:

  1. Scan each domain in the group individually.
  2. Set up templates and geolocation rules for each scanned domain.
  3. Publish each domain's script.
  4. Implement each script separately.

Hostname match check

Grouped hostnames are matched exactly against window.location.hostname. Add each hostname you need, including www and other subdomains, individually.

(06) Important considerationsParent controls

Know what the parent domain controls

  1. The parent domain must be scanned in OneTrust.
  2. The preference center cookie list and Auto-Blocking sources are based on the parent domain scan.
  3. Templates and geolocation rules are inherited; individual domain branding is not supported.
  4. Dashboard metrics and consent records for grouped domains appear under the parent domain.
  5. Download to Local is not compatible with Bulk Domain Management.
  6. Add each required hostname, including subdomains, individually.
  7. Publish the parent's production script after creating or updating the group.
  8. Extra tags on a single site can be conditioned on OnetrustActiveGroups, since categories come from the parent.
